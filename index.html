HOW TO LAUNCH ON GITHUB + SUPABASE

STEP 1 Host on GitHub Pages (Takes 2 Minutes & Free)

  1. Go to github.com/new and create a repository named apecity-1111.
  2. Upload this single file as index.html to the main branch.
  3. In your repo, click Settings → Pages, and under Branch select main and click Save.
  4. Your live mobile-ready game URL will be live at https://your-username.github.io/apecity-1111/!

STEP 2 Paste this SQL into your Supabase SQL Editor

This creates your 1,111 character state table and residential deed table:

-- 1. Table for the 1,111 Characters (Player or AI Autopilot)
create table citizens (
  token_id int primary key,
  name text not null,
  owner_wallet text,
  grid_x int default 20,
  grid_y int default 15,
  is_ai_autopilot boolean default true,
  ape_balance int default 250,
  last_action text default 'Wandering Downtown',
  updated_at timestamptz default now()
);

-- 2. Table for the 1,111 Land/Apartment Deeds
create table plot_deeds (
  deed_id int primary key,
  zone_type text default 'Suburban House', -- 'House' or 'Apartment'
  grid_x int not null,
  grid_y int not null,
  claimed_by_token int references citizens(token_id),
  building_level int default 1
);

-- Enable Realtime broadcasts for 10Hz mobile movement sync
alter publication supabase_realtime add table citizens;
alter publication supabase_realtime add table plot_deeds;

STEP 3 Why This Engine Never Crashes on Mobile Safari/Chrome

  • Single Offscreen Sprite Atlas: All 6 NFT character archetypes + buildings are procedurally baked into 1 shared texture sheet on boot (0.38 MB RAM).
  • Strict Viewport Camera Culling: Only the tiles inside the phone screen bounds are drawn each frame.
  • 10Hz Realtime Throttle: Movement packets broadcast every 100ms with linear interpolation in between.
